# 知识故事片与品牌知识（0.9.0）

开始制作 → 知识故事片 → 选择素材 → 填写想法（可留空）→ 生成。更多设置提供画幅、目标时长、音乐和字幕。旧草稿保留原模式，不自动改写输入。字幕开关也适用于原声 Vlog、原视频剪辑和已有宣传/人物模式。

作品知识库中的“品牌知识”长期保存托管规则、平台优势、小程序功能与创作偏好。模型每次策划、完善想法、生成讲稿和补充内容时读取这些资料，同时借鉴现有优秀作品获准参考的结构和标注。这是检索和提示上下文，不是训练模型；旧作品中的事实不会自动变成业务事实。

初始偏好包含：提出观众问题，讲清一个知识点，展示相关证据，自然收尾；主动考虑车辆交接、权限、费用与异常沟通。Super Ecar 名称来自用户说明。本机小程序源码中发现的功能保留为待核对资料，不作上线承诺。公开搜索未找到足以确认平台优势的权威资料，未加入未经核实的营销事实。

可以上传真实小程序截图（PNG/JPG/WebP，不超过8 MB）。截图与知识文字分别保存，重试上传不重复创建；有相关且已确认的功能资料时，故事模型可选择截图，并按对应旁白段落插入。无截图时不会绘制假界面。截图文件名不作为业务事实依据。

故事生成使用租用 GPU 上的原声识别、Qwen 策划和 Qwen 中文配音。先读取已有原声分析；无缓存时分析每段前300秒，注明未人工校对。模型选出3至6个段落与素材起点，再依照实际旁白时长精确安排镜头。当前基于原声与摘要，未做完整视觉语义识别；较短画面可循环。独立旁白不会给原片人物重新对口型。

新旁白字幕沿用配音实测分句时间；原声 Vlog/剪辑字幕基于最终合成音轨识别，保留无字幕成片备份，完整解码检查通过后才替换。关闭字幕即跳过字幕识别或烧录。专名仍需要审片校对。

接口：鉴权 `GET/PUT /api/brand-context`；PUT 携带 revision 防止覆盖其他窗口修改。鉴权 `POST /api/brand-context/screenshots?name=...&request_id=<UUID>` 接收图片，`GET /api/brand-context/screenshots/<id>` 查看。制作沿用 `POST /api/creations`，mode=`story`，无需提供 spoken_script 或 voice_id。制作进度包括原声识别、策划、旁白、画面编排、合成和检查。
