# 企业知识 → 脚本 → 自动选材 → 精剪

0.10.0 的默认故事模式支持四步，也可在脚本确定后直接选择“一键自动精剪”。

1. 企业文化、服务理念与品牌知识保存在品牌资料中。未填文化时使用已确认产品资料，不生成虚构使命或业绩。每次写稿冻结资料版本，优秀作品只提供表达与结构参考。
2. GPU 文字模型生成可编辑口语稿。故事稿通过事实引用展开成正文，当前最多180字。最终提交的正文以SHA256锁定，配音、编排和成片不会再次改写它。
3. 可以限定已选素材；未选时从素材库中择取最多12条候选，分析范围随结果保存。每条分析前600秒、最多120次技术抽帧，结合带时间戳原声文字匹配脚本。筛除明显平坦或曝光异常画面，镜头通常3–6秒，源区间不重复。此功能不等同于视觉大模型理解人物、场景或情绪。
4. 按一次生成的完整旁白安排镜头，保存精确区间与真实镜头缩略图。点击精剪复用同一画面母版和配音，添加默认配乐与可选字幕。素材不足会明确停止，不能用循环或定格掩盖缺口。

## 任务持久性

`POST /api/assembly-plans` / `GET /api/assembly-plans/{uuid}` 提供队列、原声分析、配音、镜头编排和结果状态。`auto_render=true` 把继续制作意图保存在GPU数据库，网页关闭不影响后续精剪。短暂提交失败有限次退避重试，重启后继续，失败时仍保留可用方案。

`POST /api/creations` 的 `assembly_plan_id`、最终稿摘要、素材快照、设置与脚本来源必须一致。改稿、改素材或改制作选项需重新编排。每份方案使用唯一的制作请求标识，避免网络重试或进程恢复重复生成作品。

草稿、原片和既有作品保留；生成结果仍进入剪辑与审核区，不因自动编排直接向群发布。

## 验证

后端包含锁稿、素材变化、编排文件变化、断线重试、恢复幂等、文化持久化及前端输入保持检查。媒体测试验证不重复源区间、无循环/定格、完整旁白和帧数；实际GPU验收资料保存在工作台数据目录，发布记录以本次部署核验为准。
