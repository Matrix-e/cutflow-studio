# 商剪工坊 0.12 日常使用

本说明对应 **0.12.0 源码**，新增重点是已完成作品的一句话局部改稿，以及已确认企业知识和真实小程序截图的共同使用。是否已经部署、是否通过真实成片验收，以运行服务与本轮验收报告为准。本文写成时，0.12 的品牌成片和修改成片尚未完成实机验收，不沿用 0.11 的成片结果冒充本轮通过。

## 打开与制作

双击本项目中的“打开商剪工坊.cmd”，访问 `http://127.0.0.1:8767/`。页面打开后确认 GPU 已连接。不要手填访问口令；“检查制作条件”是初步检查，提交后还会实际验证制作依赖。

1. 在“开始制作”选择或上传现有视频，等待素材就绪。
2. 写一句目标，例如：“给潜在托管车主看，讲清办理前怎样了解规则，结合 Super Ecar 的实际页面，保留现场感。”
3. 在“制作偏好”中按需选择“企业知识与故事”或“独白宣传”，其余可保持默认。若这次必须带小程序界面，将“企业知识与小程序画面”改为“本次需要使用”。
4. 点击“开始自动制作”。系统保存素材和知识版本，再进行分析、策划、制作与检查；不用搬运文案和文件。
5. 在“我的自动制作”查看阶段和结果。展开“内容方案与脚本”查看主题、实际台词及每段画面；有实际引用时还可展开“本片采用的企业知识”。制作完成后播放确认并下载。

“相关时自动使用”会按主题判断是否需要企业资料和截图；“本次需要使用”要求有已确认事实关联的真实截图，不能满足时会说明问题；“本次只用所选视频”关闭企业事实与小程序截图引用。知识解释采用旁白；原声 Vlog 不能通过改写人物录音来表达未说过的企业知识。

## 把小程序截图加入以后的视频

在“制作偏好 → 企业文化与品牌知识”或“知识库”中维护资料。只把已经确认的规则、功能与优势保存为事实；表达风格和希望传递的理念放在文化与创作偏好中。

1. 在“小程序截图”点“添加截图”，选择真实小程序页面。支持 PNG、JPG、WebP，每张不超过 8 MB。
2. 等待图片显示，点图片下方“用于视频”。已有图片也可以点“查看或修改用途”。
3. 填写页面名称或位置、来源说明和画面用途，勾选它真正对应的已确认知识。不要把官网、设计稿或示意图当作小程序截图。
4. 核对图片后勾选确认，再点“保存并用于视频”。这一步只保存用途和关联，不修改原图，也不会开始制作或对外发送。

例如，汽车助理首页可以说明提问入口；它不能证明材料已经提交、审核通过、签约完成或收益发生。系统保留具体来源与核验范围，并检查实际图片版本。修改上方知识后应重新核对对应截图；删除或改写所关联的事实可能使旧关联失效。

本轮已找到并人工查看过一张真实的 Super Ecar 智能托管汽车助理首页，准备关联“托管问答助理入口”。当前没有对应申请表单、合同、收益页的实拍图，不应为这些内容套用同一张首页。绑定是否已在运行服务执行、图片是否真正入片，须查看本轮制作记录与实际成片。

## 用一句话修改成片

在已完成作品下方“想再改一下？”输入意见，点“按这句话生成新版本”。例如：

- “删掉‘先确认目的明确’，把‘进楼’改成‘进小区’，其他内容保持不变。”
- “开头更直接，先点出托管前需要问清规则，其他段落保持不变。”
- “缩短到二十秒，保留现场原声。”

已通过的旁白作品支持局部台词修改：保留未受影响镜头和段落，重新生成受影响的声音、字幕和检查。原声 Vlog 的修改主要调整原录音片段；不能把人物未说过的话伪装成其原声。修改时长、模式或素材属于结构调整，需要重新策划相关部分，不能保证只改一处。

原版本始终保留。普通文字修改沿用父版冻结的企业知识和截图，不会悄悄换成知识库刚更新的版本。若要使用更新后的知识或换一批画面，可在主流程按新的目标创建作品。

修改后的观点仍须有依据；“还准备去聊”不能改为“已经成交”。无法执行、超出镜头时长或未通过事实检查时，会留下未完成记录和具体问题，父版仍可播放。不把失败版本标为成片，也不重置次数来无限重试。

## 交付和恢复

通过关键检查后可下载六类交付：MP4 成片、SRT 字幕、PNG 封面、标题与发布文案、制作记录，以及包含前五项的 ZIP。六类文件对应同一版本。下载、关联截图与制作本身都不会发布或向企业微信群发送。

刷新或重新打开页面后，可在“我的自动制作”继续查看。网络返回不确定时使用“核对上次提交”，不要反复新建。素材、模型或容量阻断会集中显示；解决后使用原任务允许的继续操作。达到重试上限的任务保留失败状态。

## 本轮验证边界

| 能力 | 本文编写时的状态 |
| --- | --- |
| 已确认知识保留来源与稳定关联、真实截图元数据保存、修改版本与文件校验 | 已完成代码和针对性测试；不等于 GPU 成片验收 |
| 网页关联现有或新上传截图 | 已实现，前端针对性回归通过；实际浏览器操作由本轮验收另行确认 |
| 0.12 一句话局部改稿、企业知识及截图真正入片、该品牌成片再修改 | 已接入，真实制作与成片检查尚待本轮结果 |
| 原有 0.11 已交付作品 | 保留；历史通过结果见旧版说明，不代表 0.12 新能力已经通过 |

最终验收需同时看到事实引用、清楚可读的真实截图、实际音频与字幕、下载文件，以及原版未被改变的记录。代码测试、模型回答或单独文件存在都不能代替这项验收。
