# 抖音关键词采集 v0.2

本版按网页登录方式实现，不需要购买或填写搜索接口。首批任务：汽车托管、汽车租赁沙龙、AI沙龙。部署后每 6 小时排队一次，每次最多检查 5 条视频。电脑、GPU 连接器和本机采集器均需保持运行；首次登录需要本人操作。

## 使用步骤

1. 双击项目中的 `启动抖音采集.cmd`。启动器会检查 GPU 连接，并打开独立的 Chrome 窗口。
2. 在该窗口登录抖音，完成平台要求的验证。登录完成后，按采集控制台的提示继续。登录会话保存在本项目的私有 `data/douyin-browser`，不读取你平时使用的 Chrome 配置。
3. 在工作台的「关键词采集」查看任务，点击「立即采集」，或等待定时任务。可添加、暂停关键词和查看来源。
4. 采集器读取页面上实际出现的视频链接，尝试下载页面提供的文件。下载成功后检查视频、计算指纹，保存来源记录。页面只提供不受支持的播放器地址、下载受限、文件超过 128 MB 或验证失败时，只记录链接和原因。
5. 下载的文件在 `data/collected/douyin`。双击 `采用采集素材.cmd`，选择视频并记录自有/已授权及授权依据；程序验证文件后，将副本放入指定素材投递目录，由现有同步与剪辑流程继续处理。

保持下载内容原样，不移除水印。采集到文件不等于商用权利已确认；网页中的使用标记只是整理信息，采用素材时仍需填写授权依据。未经采用的采集文件不会自动进入剪辑或企业微信。

## 状态含义

- 等待本机采集：任务已保存，等待本机采集器领取。
- 采集中：本机已领取，有时限和唯一执行凭证，防止多个窗口重复领取。
- 本轮已结束：搜索结果已入库，需查看每条结果的下载状态；不表示全部下载成功。
- 需要处理：登录、验证、浏览器或连接出现问题。处理后点击「立即采集」重新运行。
- 已下载到本机：本机采集器已校验视频并上报指纹；GPU 服务器不会假称自己已读取本机文件。

## 已验证与待验证

已通过模拟页面及接口测试：关键词队列、鉴权、重复领取、租约失效、去重、下载边界与授权记录。真实抖音页面可能调整结构；当前尚未完成登录后的真实视频下载验收，不能保证任意抖音视频都可下载。

本次 Chrome 自动操作工具因无法确认当前网页 URL 而停止，研发没有绕过该限制，也没有读取个人浏览器会话。首次实测通过上述启动器由用户完成登录，再确认实际下载数量。网页遇到验证码时需要人工处理。

## 安装与维护

本机需要 Python、FFmpeg/ffprobe、已安装的 Google Chrome，以及 `python -m pip install -r requirements.txt -r requirements-browser.txt`。GPU 仅运行采集任务管理与剪辑服务，不需要浏览器依赖。不要把 data 目录、登录会话、访问令牌或 SSH 密钥上传到公开仓库。

旧的 `配置抖音采集.cmd` 是预留的官方接口配置入口，本次网页登录方案不使用它，也没有配置或调用官方搜索接口。
