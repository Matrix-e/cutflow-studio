## 部署与日常使用

部署前核对 `data/processes.json` 与实际 API，等任务结束再切换，备份 SQLite 和私有配置，保留素材、模型、作品及凭据。重启后核对 PID、工作进程、数据量和接口；不误停其他模型服务。

普通流程为“选择或导入素材 → 写简单目标 → 开始自动制作 → 播放下载”。GPU 实例运行后，双击“打开本地工作台.cmd”打开 `http://127.0.0.1:8767/`；字幕、音乐、画幅是可选设置，内容方案与检查可展开。制作和下载不会自动群发。详见 [daily-use-v011.md](daily-use-v011.md) 与 [director-acceptance.md](director-acceptance.md)。
