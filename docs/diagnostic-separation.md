# 测试片与正式视频分离

用户看到的彩条画面是研发生成的 FFmpeg 技术测试素材，用于验证文件同步、GPU 编码和播放器，不是客户原视频或商业成片。将它们放在普通待审队列中造成了误导。

## 修复内容

- 任务持久保存 `production` 或 `technical_test` 分类，历史记录默认仍为正式任务，不按文件名猜测。
- 只有核对原文件 SHA-256 的两条既有 QA 记录归档为技术自测；保留原文件、输出、检查结果及操作记录。
- 正式素材列表、制作列表和统计排除已登记的技术测试；“技术自测（非成片）”单独显示。
- 测试详情显示用途及来源；页面隐藏审核与推送操作，后台同样拒绝审核、重剪及推送。
- 同步后的自动观察器也跳过已登记的测试素材，防止反复提交或自动推进。
- 页面只在真实服务检查通过后显示连接成功；自动连接方式与连接结果分别显示。
