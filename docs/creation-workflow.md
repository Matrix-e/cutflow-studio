# v0.5 创作流程与 API

主流程为：**开始制作 → 多选素材或多文件上传 → 写想法 → 生成 → 审片与下载**。「更多设置」默认折叠；不填时由明确的文字要求和默认值决定制作方式。

本文记录已实现的代码与本机测试，不代表 v0.5 已部署或新流程已经通过真实浏览器验收。计划部署目录为 `/root/autodl-tmp/cutflow-studio/releases/v0.5-20261103-creator`。

## 上传与生成分开

- 新入口使用 `POST /local-api/import?filename=...&mode=library&id=...` 接收每个文件，原文件不修改，单个文件上限 2 GiB。
- 文件保存到 `工作台导入/library/<导入编号>/<原文件名>`。既有 SFTP 同步保留父目录并附加内容摘要；界面以同步回执中的实际远端路径选择素材。
- GPU 观察器跳过 `library` 路径，不自动建任务，也不自动审批或发布这些素材。上传成功不等于 GPU 已同步，更不等于已经制作完成。
- 文件全部同步完成后，用户选择 1–12 段视频并点击「生成」，才创建创作任务。选择顺序就是制作顺序。
- 普通目录和原来的 `gentle`／`preserve` 路径继续执行旧观察器行为：稳定后自动入队。只想入库备选时，使用新入口，不要直接投递到旧自动处理目录。

## 当前能够执行什么

| 要求 | 实际行为 |
| --- | --- |
| 多段素材 | 按选择顺序拼接；不自动判断哪个镜头更精彩 |
| 不指定时长 | 默认保留全部可用片段，不为凑时长循环视频 |
| 指定较短时长 | 按各源可用时长比例分配开头区间，可能截断句子，方案会提示审片 |
| 目标长于素材 | 使用全部可用内容，提示时长不足；不自动补拍、变速或循环 |
| 横版、竖版、方形 | 等比适配对应画幅，必要时留边；不自动裁人脸 |
| 保留完整节奏 | 不清理静音；若另外指定更短目标时长，仍会执行时长裁切 |
| 保守／紧凑节奏 | 按声学静音清理停顿，不判断句意、口误或重复内容 |
| 开头标题 | 在开头画面上叠字，不新增黑屏片头；任务名称本身不自动成为画面标题 |
| 加轻音乐 | 添加原创程序合成音乐，有原声时压低音乐；不搜索商业曲库 |
| 不加音乐 | 不额外添加配乐；原视频中已有音乐仍属于原声，默认保留 |
| 原声开关 | 控制现有音轨；不是语音分离或生成新配音 |

明确的「更多设置」选项优先于文字推断。可执行示例：

> 做成 30 秒竖版，保留原声，片头标题为“汽车托管”，加轻音乐。

本流程不支持语义选亮点、重写内容、新配音、自动字幕、自动补镜头、复杂转场、专业调色或去水印。提出这些要求时会显示限制提示，不能把“文件成功导出”理解为所有想法都已经执行。技术检查通过后仍需观看成片，检查切点、标题、音乐与内容表述。

## 创建接口

`GET /api/config` 返回 `creation_supported: true` 表示 API 支持创作。该字段不能单独证明远端观察器也已升级。

`POST /api/creations` 需要 `Authorization: Bearer <工作台访问令牌>`。使用已同步素材在 `GET /api/assets` 返回的 `source`，不要自行拼接机器绝对路径或同步摘要。

```json
{
  "sources": ["门店/外景.mp4", "门店/讲解.mp4"],
  "brief": "做成30秒竖版，保留原声，片头标题为“门店介绍”，加轻音乐。",
  "options": {},
  "idempotency_key": "creation-example-001"
}
```

| 字段 | 约束 |
| --- | --- |
| `sources` | 1–12 个有序、不重复的素材相对路径；须存在、非空、格式受支持且在投递箱内 |
| `brief` | 必填，去除首尾空白后非空，最多 3000 字符 |
| `title` | 可选任务名称，最多 160 字符；留空使用想法前 30 字 |
| `options` | 可省略或传 `{}`；只接受下表中的字段，未知键会拒绝 |
| `idempotency_key` | 必填，非空，最多 200 字符；同一次提交重试应保持不变 |

| `options` 字段 | 值与含义 |
| --- | --- |
| `target_duration` | 1–3600 秒的数字，或 `null`；`null` 明确取消目标时长，省略则允许从想法解析 |
| `aspect` | `original`、`16:9`、`9:16`、`1:1`；默认沿用首段画幅 |
| `keep_original_audio` | 布尔值；默认 `true` |
| `pace` | `preserve`、`gentle`、`compact`；默认 `preserve` |
| `opening_title` | 最多 120 字符、不含控制字符；默认无标题 |
| `music` | 布尔值；默认不额外添加配乐，明确文字要求可改变它 |

界面的“自动”通过**省略该选项**表示。不要发送 `aspect: "auto"`、`duration` 或 `music: "light"` 等旧草案字段。

新建返回 HTTP 201，幂等重放或相同进行中任务合并返回 HTTP 200：

```json
{
  "job": {
    "id": "任务编号",
    "status": "queued",
    "brief": "原始想法",
    "sources": ["门店/外景.mp4", "门店/讲解.mp4"],
    "creation_plan": {
      "resolved": {},
      "summary": ["实际解析的制作步骤"],
      "warnings": ["无法执行或需要审片确认的要求"],
      "source_count": 2,
      "stage": "interpreted"
    },
    "creation_warnings": ["无法执行或需要审片确认的要求"]
  },
  "created": true,
  "owned_by_request": true
}
```

`resolved` 实际包含已解析的完整选项。分析完成后 `creation_plan.stage` 变为 `planned`，并带有实际计划时长 `duration`；方案与限制同时保留在任务详情中。`summary` 是文字数组，界面可逐条显示。`GET /api/jobs/{id}` 和既有任务列表、审片、下载接口继续使用。

## 持久化、重试与发布

- 既有 SQLite 任务表继续使用。`settings.creation` 保存版本号、想法、选项、解释，以及所有源文件的相对路径、大小、修改时间和变更时间。
- 去重指纹覆盖有序素材版本、想法、选项、任务名称与编码配置。相同请求编号换了素材版本或要求会返回 409，不覆盖原任务。
- 入队、执行、分析后、渲染后与失败重试均校验全部来源。第二段或第三段变化也会阻止任务进入审片；原文件不被修改。
- 已登记的技术测试素材在任意选中位置都会被拦截，数据库事务在入队和关键状态转换时再次校验。
- 失败重试仍用 `POST /api/jobs/{id}/retry`；以 `can_retry`、`retry_block_reason` 显示入口。发送失败或发送结果未知不能用普通剪辑重试绕过发布保护。
- 创作入口只生成待审任务，不自动审批和发送。旧观察器的自动发布配置只适用于它自己创建且满足检查条件的任务。
- MP4 是正式下载与发布文件。WebM 兼容预览独立生成，不替代交付文件，也不改变任务状态。

## 部署顺序

**必须先升级 GPU 观察器，再启用本机 `library` 上传。** 旧观察器可能把新目录里的视频当普通素材自动入队；仅更新网页或仅重启 API 不足以切换行为。

1. 将同一版本的 `studio/server.py`、`store.py`、`creative.py`、`watch.py`、`profiles.py` 及配套文件部署到 `/root/autodl-tmp/cutflow-studio/releases/v0.5-20261103-creator`。原始素材与数据库继续使用既有共享数据目录。
2. 停止旧远端观察器及相关旧守护进程，确认旧观察器不再监测。用新目录的 `scripts/run_gpu.py` 启动 API、渲染进程和观察器，避免新旧观察器并行。
3. 确认 API 返回 `creation_supported: true`，并另行核对实际观察器进程使用的是新发布目录。检查它能跳过 `工作台导入/library/...`，同时原非 `library` 行为仍符合预期。
4. 中文标题需要可用中文字体。当前环境采用 Ubuntu `fonts-wqy-zenhei` 包，仅解压至数据盘 `data/fonts/wqy-package`，链接到 `/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`；不需要改动 GPU 驱动包。换机时检查 FFmpeg 的文字绘制组件与字体文件，不要把缺字当成标题已经正确输出。
5. 再更新并重启本机网关、刷新工作台，开放新入口上传。确认仅入库不产生任务；选择已同步素材、填写想法、点击生成后，才应出现一条任务。验证重复点击、失败重试、播放和下载。

GPU 关机或同步暂不可用时，本机已接收的文件保留等待。新创作只能选择确认已同步的素材；不能把本机入库成功显示为远端制作完成。
