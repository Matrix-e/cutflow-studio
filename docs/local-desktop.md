# 本地网站使用说明

打开地址：http://127.0.0.1:8767/

桌面快捷方式：商剪工坊。也可双击项目中的 `打开本地工作台.cmd`。

网站文件在这台 Windows 电脑上运行；页面通过本机的加密连接访问既有远端 GPU。实际剪辑、任务数据和成片仍由 GPU 服务处理。这样可以继续使用原有三个关键词任务、素材和审核记录。

本地页面自动连接，不需要手工填写「剪辑服务地址」或「工作台访问令牌」。刷新页面后会自动恢复连接。截图里的两个输入框是云端入口的手工连接方式；使用本地入口时改为显示「已启用本地自动连接」。GPU 访问凭据留在本地服务进程中，浏览器获得单独的临时本地凭据。

本地服务只监听 127.0.0.1，其他电脑无法通过局域网访问。网页放在本地不代表离线剪辑：远端 GPU、网络以及连接器需要运行。关闭浏览器不会停止后台服务；重启本机后，双击桌面快捷方式重新启动即可。本次没有设置开机启动或修改云端站点。

本机使用 8767 端口；8766 是 GPU 加密连接入口，8765 是旧的独立 CPU 备用模式，不需要同时启动。端口被其他程序占用时，启动器会明确停止，不覆盖已有程序。

2026-11-03 已实测：启动本地网站、读取 GPU 状态及原有任务、页面自动连接、刷新后自动连接。浏览器页面已显示「工作台已连接」，设置页不再要求填写地址与访问令牌。
