## 启动和日常使用

1. 确保租用 GPU 实例运行，双击“打开本地工作台.cmd”，打开 [本地工作台](http://127.0.0.1:8767/)。页面与 GPU 连接分别显示，不需填写模型名和访问令牌。
2. 选择已就绪素材，写一句目标，点“开始自动制作”。画幅、音乐、字幕和时长可以使用默认值。
3. 在“我的自动制作”查看实际阶段，完成后播放和下载；需要时展开方案、分镜与检查记录。
4. 写一句修改意见建立新版本，原版保留。本例“缩短到20秒，开头更直接，保留现场原声”已实际通过；新的修改要求仍应查看实际效果。
