# v0.4 本机导入与审片体验

这版修复实际使用中“只给 GPU 目录、不知道如何投递”“品牌片仍被裁静音”“只有推送、没有下载”的阻碍。原始媒体不会被覆盖。

## 操作

1. 双击桌面商剪工坊，打开素材库。
2. 选择或拖入一个视频，选“口播保守处理”或“保留完整”，点击导入。支持 MP4、MOV、MKV、WebM、AVI、M4V、MTS，单文件最多 2 GiB。
3. 看本机导入列表，从等待同步到已同步，再到对应的制作任务。不要因等待而反复新建任务。
4. 预览原片、查看处理结果，点击下载成片。只有需要发送群消息时才使用审核和推送。
5. GPU 暂不可用时可先把文件导入本机；若连接器未运行，重新双击桌面入口启动连接。页面不会把本机保存成功说成 GPU 已完成。

## 处理方式

- 口播保守处理继承当前全局设置，使用长停顿识别，不做语义精剪或口误识别。
- 保留完整关闭去静音，保持完整时间范围和原比例；仍会转为统一的 H.264/AAC，并整理音量。输出不是逐字节拷贝原视频。
- 固定的 `工作台导入/gentle|preserve/导入编号/文件名` 目录随 SFTP 一起传输。GPU 根据该明确协议选择设置，避免参数后到而先错误剪辑。
- 同一次失败上传重试保留编号，服务器核对内容；内容不一致时不会覆盖已有文件。
- 本机播放通过仅限媒体读取的临时会话权限支持 Range 分段请求，不把整部课程一次装入 JavaScript 内存。远端页面保留已有鉴权兼容方式。
- 原片是否能在浏览器播放取决于编码；不兼容的容器仍可导入，由 GPU 输出浏览器兼容版本后审片。
- 技术自测保持独立，不可作为正式成片审批、推送或下载。
- 发布结果不确定的任务不提供普通重试，避免重复发群。

## 验证范围

自动测试覆盖无 GPU 时本机导入、文件校验、路径保护、大小和磁盘限制、幂等重试、专用媒体会话权限、Range、模式沿用、原片不变、完整时长渲染、任务重试边界与旧连接状态回归。实际浏览器与 GPU 的本次验收另保存在交付目录中。

抖音首次登录与企业微信 Webhook 仍需用户配置；本轮不会声称这两项已真实完成。口播语义精剪与长期无人值守质量仍待原视频验证。
