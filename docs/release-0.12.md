# 商剪工坊 0.12.0 发布说明

日期：2026-11-05。这是 CutFlow Studio 第一次公开源码版本。运行中的 GPU 发布仍可能是 0.11.4；下文把“已经用真实成片验收”和“这版源码新增、尚未重新出片”分开写。

## 复盘：0.11.4 实际交付了什么

0.11.4 是一条能从素材走到成片的自动制作链路。本机交付在 `视频自动化项目/交付成片/2026-11-04`。

同时通过的还有：刷新后恢复、重复提交不新建任务、原版保护、素材不足时阻断、必要服务故障预检，以及一次真实低音量缺陷的自动修复。六个原有制作入口做过技术实测。当时的回归是 Python 698 项加 444 个子测试、前端 185 项。这些测试不能代替上面的成片。

## 复盘：0.11.4 没有完成的部分

企业故事的自然语言润色子版 `608013d5-6261-4605-9fb8-fa6646665f92` 三次都停在内容核对，没有成片，父版保持原样。失败是两类问题叠在一起，不能只归咎于审片误报：

- 误报：旁白仍是“接下来进小区”“准备去聊”，审片把它说成已经发生。
- 真问题：把“叫我坐一会儿”写成“我就在物业坐着”；结构摘要里的“先规划好路线”没有进入台词或原声；观点字段写了方法，实际台词没有对应句子，审片却可能给出空引用。

当时也还没有这些端到端证明：品牌知识自动进入成片、小程序截图入片、新自动链里的数字人、任意原片换脸换衣换背景、字幕自动修复和强制中断后续作、企业微信群机器人实发。GPU 数据盘当时约剩 2.22 GiB，不适合长期堆积成片。

## 0.12.0 针对上述缺口做了什么

源码里已经接上、并用测试锁住的部分：

- 已通过成片可以按一句话做局部改稿。明确的删句、替换、开头和结尾要求先按字面执行，不重新选镜头，父版保留。
- 事实台账把原声分成计划、收到安排、尚未发生、人物自述的当前或完成状态。改稿不能把“叫我坐一会儿”推进成“正在坐着”，也不能写无依据的签约、收益或交付。原先这个守卫在命中后一句不含该动作的台词时会崩溃，现在会稳定拒绝并保留父版。
- 观点型成片必须从当前台词逐字引用认识或方法。只写在主题字段里不算通过。
- 审片若把仍保持计划语气的句子判成已发生，而事实守卫也确认台词没有升级状态，这条意见会被撤销并记入 `dismissed_plan_state_issues`。真实的状态升级和缺少观点依据仍会挡住成片。
- 标题、简介和结构摘要不能凭空写“已经规划好路线”或未被原声支持的业务结果。
- 已确认的企业知识和真实小程序截图可以绑定到制作；截图只说明界面，不证明签约、审核或收益已经发生。

## 这版仍然不能算完成的部分

- 上述守卫没有在 GPU 上用一条新成片再验收。0.11.4 的五条成片不能用来宣称润色已经稳定。
- 品牌知识和小程序截图还没有“从绑定到成片画面”的端到端证明。
- 数字人、换脸、换衣、换背景不在这版能力内。
- 企业微信仍是独立发送；未配置机器人时不会发送。
- 本仓库不包含素材、成片、模型权重、访问令牌或 GPU 运行数据。
