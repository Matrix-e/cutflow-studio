## 打开

双击桌面“商剪工坊”或项目里的“打开本地工作台.cmd”，然后使用 `http://127.0.0.1:8767/`。本地启动器负责页面、GPU 连接与素材同步；无需手填地址、访问令牌或模型名称。电脑重启后再次双击即可。

先看右上角 GPU 连接状态。页面能打开不等于 GPU 已连接，GPU 已连接也不等于所有生成服务已验证。第一次制作可点“检查制作条件”，它只做初步检查；正式任务在处理素材前会实际验证所需模型与声音。

## 做一条新视频

1. 在“开始制作”上传视频，或勾选已有素材。上传只入库和同步，不会立即开始剪辑。等待所选文件就绪，最多 12 段。无需先调整顺序，系统根据内容取舍；不选时自动从素材库选择候选，分析范围会保存在制作记录中。
2. 写一句目标，比如“保留这次走访的真实过程，让观众理解一个值得关注的现场发现”。没有明确选题，可点“让素材决定主题”。不要把未知活动结果或未经确认的业绩作为事实填写。
3. 点击“开始自动制作”。同一个任务会依次处理主题、观点、脚本、分镜、剪辑、声音、检查和交付，任一关键检查未通过会集中显示问题并保留成果。画幅、字幕、音乐和目标时长在“制作偏好”中可选，不改也能提交。
4. 在下方“我的自动制作”查看当前步骤。可以展开内容方案、分镜、检查记录与制作日志。只显示实际阶段，不显示虚构百分比或剩余时间。关闭网页后任务仍保存在 GPU 服务，重新打开可继续查看。
5. 成片就绪后播放确认。可分别下载视频、字幕、封面、标题与发布文案、制作记录，或下载完整交付包。下载不会审核、发布或发送到企业微信群。

目标时长是策划参考，不是强制填满。素材不能支撑时，系统应缩小主题、缩短长度或说明缺口；不会把静音、空白、反复循环或无关镜头当作正常交付。

真实审片测试中，有依据的建议可以通过，无依据的“已完成交付”“收益一万元”会被阻断。日常使用仍应核对片中业务事实；这组通过的测试不能保证识别所有错误表达。

## 修改与继续

- 在“我的自动制作”选中作品，找到下方“想再改一下？”，写一句修改意见，例如“开头更直接”“缩短到一分钟”“保留更多现场原声”，点击“按这句话生成新版本”。只有已有方案、当前不在运行且服务允许修改的任务才显示该区域。原版本保留，受影响的制作与检查会重新执行；查看新标题、方案和实际内容，确认本次意见得到落实。

- 若还没有生成可保存的方案，就不会显示修改入口。可以调整上方目标或所选素材，提交一个新的任务；原失败记录保留。
- “需要补充条件”会集中列出问题。恢复模型、同步素材或解决容量问题后，使用该任务的继续按钮。不会删除已有分析与方案。
- “核对上次提交”表示网络返回不确定。点击它会查询原任务编号；不要重新上传同一批文件。目标、素材和设置没有变化时，再次点击主按钮只查看已提交任务。
- 达到重试或处理时长上限后，任务保留为未完成，不无限重试。已保留的方案可以用于明确的新版本。

## 下载交付

新自动作品只有在关键质检通过且交付文件齐全后，才在播放器下方显示下载按钮。六类文件始终对应所选作品的同一版本；单击下载只读取文件，不重新制作、不审核也不发布。

| 按钮 | 下载内容 |
| --- | --- |
| 下载成片 | MP4 视频，保留原画质 |
| 下载字幕 | SRT 时间轴字幕；关闭画面字幕时仍保留字幕文件 |
| 下载封面 | 从已选原素材抽帧并排当前标题的 PNG；本轮单标题封面已查看验证，历史封面保留 |
| 标题与发布文案 | TXT 文件，包含作品标题与简短文案 |
| 制作记录 | JSON 文件，包含内容方案、素材来源、版本与质检记录 |
| 完整交付包 | ZIP 文件，包含以上五份交付文件 |

“交付信息待核对”或失败、阻断状态不开放这些下载，不能作为已经完成的视频。六个旧入口的成片在“剪辑与审核”中播放并点“下载成片”，不保证旧任务具有新流程的六类交付包。

本轮主版已完成浏览器 MP4 与 ZIP 下载；独白与显式 Vlog 已逐一验证六类附件。显式 Vlog 已在浏览器播放到 26.5 秒并下载 ZIP；最终修改版完整播放至结束，ZIP 实际下载、解压均通过。完成状态只代表该版本通过所列检查，不保证每种素材、每个模式或每句修改都能自动达到发布品质。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 8767 页面打不开 | 再次双击“打开本地工作台.cmd”。保留启动器提示；不要删除项目 data 或重装覆盖。 |
| 页面可见，GPU 未连接 | 确认租用实例运行、网络可用；启动器会重试连接。素材和任务保留。 |
| GPU 已连接，但模型未就绪 | 按集中检查报告恢复所列服务。模型文件存在不代表推理可用；任务不会越过关键阻断开始正式制作。 |
| 上传后仍不可选择 | 查看同步状态，等全部就绪；单段最大 2 GiB。读取失败不会把现有原文件判定为删除。 |
| 成片不符合目标 | 查看内容方案与素材依据，提出具体修改；若原素材不足，应补素材或缩小主题。 |
| 下载或播放失败 | 检查连接，刷新任务后重试读取。原有手动模式提供兼容预览；新自动作品保留原画质下载。 |

本机启动器不能替代租用平台开机。GPU 容器重启后，如服务未自行恢复，需要恢复当前发布版本的服务进程；不要复制旧文档中的历史版本命令。模型、素材、任务数据库和成片位于 GPU 数据盘，释放租用实例前应另行备份。当前服务版本与验收结果以运行状态和本次验收报告为准。
