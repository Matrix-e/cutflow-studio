# 商剪工坊 · CutFlow Studio v0.5

为口播、课程、访谈搭建的本地素材接收、GPU 同步、视频制作、审片与企业微信内部群交付系统。v0.5 的主流程是“选择素材 → 写想法 → 生成”，支持按顺序拼接多段视频、时长与画幅设置、开头标题和可选轻配乐。它仍是研发原型，尚未达到无人值守商用精剪验收标准。

**v0.5 验证状态：** 本机 Python 测试 257 项通过（含 116 个子测试），Node 测试 54 项通过。本说明不代表 v0.5 已部署到 GPU，也不代表新流程已完成真实浏览器验收。升级顺序见 [创作流程与部署说明](docs/creation-workflow.md)。

## 先用起来

1. 双击桌面 **商剪工坊**，或本目录 **打开本地工作台.cmd**。网站在本机 `http://127.0.0.1:8767/` 运行，自动连接远端 GPU，无需填写服务地址或令牌。后台连接器与网站持续运行，可关闭启动窗口。电脑重启后再次双击即可。
2. 打开「开始制作」，多选已同步素材，或一次选择多个本机视频上传。单文件最多 2 GiB；原文件不修改。新入口的上传**只入库和同步，不自动创建剪辑任务**。等待所选文件全部显示已同步后，按希望播放的顺序整理素材，单次最多选择 12 段。
3. 写下想法，例如：`做成30秒竖版，保留原声，片头标题为“门店介绍”，加轻音乐。`「更多设置」默认折叠，可以不填；展开后设置的明确选项优先于文字描述。
4. 点击「生成」。页面会显示实际解析的制作方案和能力限制。任务在 GPU 上依次分析、渲染、检查；目标时长较短时会按比例使用各素材的开头区间，不会自动理解或选择“精彩片段”。
5. 在「剪辑与审核」观看结果和检查报告，点击「下载成片」保存 MP4。播放器不兼容时可手动生成 WebM 兼容预览，下载与发布仍使用原 MP4。只有技术检查通过的正式成片才能审核和推送；安全可重试的失败任务会显示重试入口。
6. 首次接企业微信时，双击 **配置GPU企业微信.cmd**。在本机隐藏输入群机器人的 Webhook，不要发到聊天里。配置经 SSH 写入远端私有运行目录，权限为 0600，不在本机保存，不发送测试消息。刷新工作台后可审核并推送。

**旧目录监测流程仍保留。** 直接放进以下素材目录、原来的 `gentle`／`preserve` 导入，以及其他非 `library` 路径，仍可能由观察器自动创建任务。希望“先备齐素材，再点击生成”，请使用新的「开始制作」上传入口；它保存到 `工作台导入/library/导入编号/文件名`。

`C:\Users\Administrator\Desktop\空间同步\BaiduSyncdisk\公司材料空间\视频素材`

**抖音网页登录采集：** 双击 `启动抖音采集.cmd`，在独立 Chrome 中登录，再在工作台「关键词采集」管理任务。首批关键词为汽车托管、汽车租赁沙龙、AI沙龙。下载成功的素材先保存在本机，双击 `采用采集素材.cmd` 记录授权依据后进入原素材投递流程；该流程仍可能自动入队。详细步骤与验证边界见 [采集使用说明](docs/browser-collection.md)。真实抖音登录与下载尚待实测，普通网页可看不保证可下载。

当前本机访问 GPU 的地址是 `http://127.0.0.1:8766`，仅在连接器运行时可用。连接使用专用密钥；服务器主机公钥在首次连接记录，此后严格匹配。密钥只允许 SFTP 和远端 `127.0.0.1:8765` 的端口转发，不能运行远端 shell 命令。按 Ctrl+C 关闭本机连接器，不会关闭租用的 GPU 实例。

双击 **连接GPU工作台.cmd** 会复用已运行的连接；尚未连通时，连接器会持锁等待并重试，认证 GPU 后才启动同步。双击 **停止本机同步.cmd** 可以停止本项目的本机同步与转发。它不会关闭 GPU 实例或删除素材。

**启动工作台.cmd** 是独立的本地 CPU 备用模式，运行在 8765 端口；不要与 GPU 流程同时启用自动发布。本机依赖已准备。换电脑时需要 Python 3.10+、FFmpeg 和 `python -m pip install -r requirements.txt`，并重新配置专用连接密钥。

## 当前已实现

- 原文件不修改；持续监测、稳定等待、内容哈希与任务去重。
- SFTP 同步到指定 GPU 数据盘：临时文件、远端校验、原子落盘、失败重试。需要配置 SSH 密钥和已核验的主机指纹。
- 多选 1–12 段已同步视频并按选择顺序合成；上传入库与“生成”分离。任务保存全部素材版本、原始想法、解析方案和限制提示。
- 从明确文字或选项解析目标时长、横竖画幅、原声、停顿处理、开头标题和轻配乐；标题叠加在画面上，配乐为原创程序合成，原声存在时压低音乐。
- 长静音保守修剪，保留讲话原速；明确记录每段原片与成片时间；等比适配画幅，避免随意裁掉人物。
- H.264/AAC 渲染、音量整理、完整解码与时长检查；保留计划、检查报告与任务事件。
- 手动请求 VP9/Opus WebM 兼容预览；独立缓存，不替换正式 MP4，不改变任务审核或发布状态。
- 已有 SRT 的时间轴重排。另有可选的离线语音转写命令，但没有下载模型，也没有验证真实 GPU 推理。
- 企业微信内部群的 MP4 文件上传与发送接口；限流、已发送去重、结果不确定时停止自动重发。
- 中文工作台、持久任务队列、异常恢复、鉴权、明确的失败状态。

**创作主流程尚不支持：** 语义选亮点、可靠删除口误与重复句、内容改写、生成新配音、自动生成或烧录字幕、自动补镜头、复杂品牌模板、转场特效和专业调色。相关要求会显示能力限制，不会伪称已经完成。独立转写命令不等于已接入此流程。真实 ASR 模型推理、真实企业微信投递、开机自动启动服务和长期无人值守运行仍未验收。声画元数据与解码通过，也不等于内容和审美质量通过。

## 配置与自动化

`config/local.json` 保存本机非敏感连接参数，`config/preset.json` 保存剪辑参数。改变设置后重启启动器。环境变量优先于本机配置。工作台访问令牌首次启动生成在 `data/access-token.txt`，只用于本机控制台，已排除出 Git、GPU 源码包与发布包。

新「开始制作」入口上传后只入库，用户点击「生成」才创建任务，随后手动审片和发送。非 `library` 路径继续沿用原观察器的自动处理行为。完成固定栏目与模板的真实验收后，可设置 `CUTFLOW_AUTO_PUBLISH=1`，并配置机器人且启用 `CUTFLOW_PUBLISH_ENABLED=1`。观察器只会自动发布自己创建、技术检查通过的任务；不会自动发布新创作入口手动提交的任务，也不会替代内容审核。发布默认关闭，实际开关以运行配置为准。

**连接GPU工作台.cmd** 已经实现本机同步 + SSH 转发，远端观察器和渲染服务由独立守护程序管理。它不是 Windows 开机服务；本机重启后需要再次启动。GPU 实例重启后需要重新启动远端守护程序，当前尚未修改容器的启动配置。

v0.5 的计划发布目录为 `/root/autodl-tmp/cutflow-studio/releases/v0.5-20261103-creator`，独立 Python 位于 `/root/autodl-tmp/cutflow-studio/runtime/bin/python`。**先部署并切换远端 API 与观察器，再启用本机 `library` 上传。** 旧观察器不能正确区分“只入库”素材，不能只刷新网页而保留旧观察器。详见 [部署顺序](docs/creation-workflow.md#部署顺序)。

完成该版本部署后，实例重启可在远端运行以下入口；版本目录尚未部署时不要直接执行：

```sh
nohup /root/autodl-tmp/cutflow-studio/runtime/bin/python /root/autodl-tmp/cutflow-studio/releases/v0.5-20261103-creator/scripts/run_gpu.py > /root/autodl-tmp/cutflow-studio/data/supervisor.log 2>&1 < /dev/null &
```

该入口自动读取已有访问令牌；不需要把令牌放入命令行。远端运行数据在 `/root/autodl-tmp/cutflow-studio/data`，原始同步素材在 `inbox`，成片在 `data/renders`。系统盘没有安装新模型，依赖和缓存都放在数据盘。

## 远程 GPU 部署

项目默认目录为 `/root/autodl-tmp/cutflow-studio`。用户截图显示系统盘使用接近 90%，数据盘较空；实际部署前仍需运行 `scripts/doctor.py` 核实。

以下步骤用于换机或重新部署。当前服务器的首次连接、密钥配置与源码部署已经完成。

1. 首次 SSH 连接时核对服务器身份，配置专用 SSH 私钥，私钥只保存在本机。不要把密钥内容写进源码。
2. 配置环境变量 `CUTFLOW_SSH_HOST`、`CUTFLOW_SSH_PORT`、`CUTFLOW_SSH_USER`、`CUTFLOW_SSH_KEY`、`CUTFLOW_SSH_KNOWN_HOSTS`。前 3 项已记录在 `config/local.json`；单独运行命令时请加载这些配置或设环境变量。
3. 使用 `python scripts/deploy_gpu.py --dry-run` 查看源码包内容；使用 `--upload` 上传。此脚本不覆盖运行中的项目，也不自动远程执行。
4. 在 GPU 数据盘解包到新目录，运行 `bash scripts/remote-install.sh`。按输出启动服务和 `python -m studio.watch --settings config/preset.json`，二者需要相同的 `CUTFLOW_INBOX`、`CUTFLOW_DATA`、`CUTFLOW_TOKEN`。
5. 本机可使用 `ssh -p 10893 -L 8766:127.0.0.1:8765 root@connect.westb.seetacloud.com` 转发，浏览器访问 `http://127.0.0.1:8766`。保持远端服务只监听回环地址；该访问方式无需向公网开放剪辑服务。

详细接口和接入限制见 [集成说明](docs/integrations.md)。商业化路径和验收清单见 [研发架构](docs/architecture.md)。

## 企业微信的实际限制

当前群机器人通过**文件消息**发送 MP4，接收者可以下载查看。单文件限制为 **20MB**；超出时会明确阻止发送。本版尚未实现长课自动分段、私有下载链接或较小发布版转码，所以不能宣称任意长视频自动发布已经闭环。保留高质量母版，不为满足附件限制无条件压低画质。

## 可选离线转写

在独立环境准备 `faster-whisper` 与本地 CTranslate2 模型后，可执行：

```text
python -m studio.transcribe 素材.mp4 --model-dir 本地模型目录 --output-dir 字幕目录 --device cuda
```

模型目录必须包含所需模型文件，程序不自动下载模型。输出原片时间轴 SRT 与逐词 JSON；不是成片烧录字幕，需校对。此入口只完成模拟测试，真实 CPU/GPU 推理未验证。参考 [faster-whisper 官方项目](https://github.com/SYSTRAN/faster-whisper)。
