## 启动与制作

1. 双击桌面“商剪工坊”或项目中的 **打开本地工作台.cmd**，访问 `http://127.0.0.1:8767/`。本地启动器管理页面、GPU 连接与同步，无需手工填写访问令牌。电脑重启后再次双击。
2. 在“开始制作”勾选已有素材或上传视频；单次最多 12 段、每段最多 2 GiB。上传只入库与同步，等所选素材就绪后再提交。不选择时自动从库中挑选候选，实际分析范围随记录保存。
3. 写简单目标，或点“让素材决定主题”。“制作偏好”提供表达方式、目标时长、画幅、字幕、音乐及企业知识入口；已有默认值。
4. 点击 **开始自动制作**。系统先检查条件，再理解画面与原声，选择有依据的主题，保存统一内容方案、脚本与分镜，然后剪辑、混音、渲染、检查并整理交付。过程无需在页面间搬运文案和文件。
5. 同页“我的自动制作”显示实际阶段及问题，可展开方案和检查记录。关键检查未通过不能标记为成片就绪。完成后可播放、下载 MP4、SRT、封面、发布文案、制作记录或完整 ZIP。
6. 想修改时写一句意见并生成新版本。原作品保留，相关方案、声音、画面和字幕会随新版本更新。发布、群推送是独立操作，不包含在自动制作中。

详细说明与排障见 [日常使用说明](docs/daily-use-v011.md)。

## 内容与制作依据

- 现有素材优先。画面采用有限真实抽帧分析，原声使用带时间戳转写，记录文件和源区间；不根据文件名臆测内容，不识别或猜测人物身份。
- 内容方案包含主题、核心观点、受众价值、素材依据、叙事结构与风格。无明确选题时比较候选方向；事实和对白必须有依据。企业文化与确认的品牌知识随任务冻结版本。
- 原声模式保留被选句子的原话和自然语速，保守整理无效间隔；旁白模式只使用锁定稿件生成声音。镜头使用经过分析的来源与时间位置，不用重复或冻结补足时长。
- 渲染后检查实际输出，包括完整解码、规格、黑画面、冻结、音轨和字幕时间、重新识别的台词，以及实际成片帧的内容和可读性。检查结果、失败区间和修复记录保留。
- 本轮真实正反审片检查通过：有素材依据的普通建议可以通过；无依据地声称完成交付或收益一万元会被阻断。该组 `all_verified=true` 结果仅证明已测案例，不保证自动发现所有虚构或误导表达。
- 初步条件检查不等于模型实测。正式制作前统一验证所需服务；外部服务失败不以空白、静音或不相关内容冒充成功。

## 任务、恢复与费用

新链路通过 `/api/productions` 保存独立任务、阶段成果及版本。浏览器先保存唯一请求编号；重复点击、网络核对和刷新不重复创建同一次任务。不同目标或修改意见形成新版本。服务重启后校验并复用完整阶段成果，不把未完成的文件当作成功输出。

重试最多 3 次、局部修复最多 1 次、任务处理预算最多 1 小时。超限保留已有成果并报告问题。使用本机和已租用 GPU，不调用另行收费的外部生成接口；GPU 租赁仍按平台原有规则计时。暂不显示无法可靠估计的剩余时间或费用。

运行数据与源码发布分开保存。GPU 项目根目录为 `/root/autodl-tmp/cutflow-studio`：素材在 `inbox`，旧任务与作品在 `data`，新自动制作数据库为 `data/productions.sqlite3`，制作记录和中间文件在 `data/productions`。实际名称以当前代码和运行目录为准，升级时备份数据库并保留原素材。不要用清空 data 方式解决连接问题。

## 保留的制作方式

首页“其他制作方式与手动编辑”保留所有原有模式；旧作品改版与草稿恢复自动打开对应模式。

| 方式 | 使用与边界 |
| --- | --- |
| 人物口播 | 公共合成肖像或已授权个人正面照片，生成口型同步。身体静态，背景和服装来自所选肖像；任意换装、全身动作不在当前能力内。 |
| 独白宣传、企业／沙龙宣传 | 明确讲稿、素材与活动事实后制作。原路径按所选顺序组织画面，不应当作新自动流程的完整语义策划。 |
| 原声 Vlog（手动） | 保留原声并整理所选素材；可选字幕与已接通的补充功能。是否可用需按实际依赖检查。 |
| 旧企业故事自动精剪 | 基于原声文字与技术画质的编排，保留锁稿与不重复区间；不等同于视觉语义理解。首页自动选题、独白与新企业故事模式均已有对应实测成片，内容范围以各实例为准。 |
| 只剪原视频 | 保守处理停顿与编码，保留原速；不是可靠识别所有口误或重复观点的工具。 |

企业微信仍为独立审核及发送流程。机器人未配置时不发送；旧文件消息存在大小约束，不能假定任意长片都能直发。抖音网页采集入口保留，但真实登录下载仍需单独验收；可观看不等于已取得下载或商业使用授权。

## 当前具体限制

- 自动选题、显式原声 Vlog、独白、企业故事和本轮修改实例已有实测结果。企业故事的本例品牌事实引用为空，品牌事实自动运用与全部沙龙主题仍为接入但未验证。
- 企业故事措辞修改任务 `608013d5-6261-4605-9fb8-fa6646665f92` 最终失败，`content_check_failed`，3 次尝试达到上限，无交付文件；原父版不变。任意自然语言润色不能视为已稳定完成的能力，也不能把父版结果当作该子版结果。
- 一句话修改已验证本轮“开头更直接”的内容、标题及方案同步，原版保留。其他修改表达仍需逐条检查实际效果，技术检查通过不能替代编辑意图核对。
- 当前封面从已选原素材抽取干净画面，再排当前标题，单标题本例已实机查看通过。历史封面不被自动覆盖；字幕可读性与封面审美仍需实际观察。
- 视觉理解是有范围的抽样，而非逐帧完整理解；每份记录应显示分析范围。机器转写存在同音字误差，人物口型、主观审美与最终业务表达仍需实际播放抽查。
- 原声的自动取舍必须受到语义和完整句约束，不能保证自动修正所有口误。用户需要新的事实或人物言论时，应补充真实依据。
- 旧手动模式与新自动链路的内容能力不同。入口不能隐藏或只靠文案宣称等效，逐项运行结果见本次验收报告。
- 本机启动器不是 Windows 开机服务，也不能启动已关机的租用实例。GPU 容器重启后的服务恢复需使用当前发布版本；不运行历史文档中的固定旧目录命令。
- 目前仍是研发验收产品；代码检查、自动测试、实际模型调用和真实成片验收分别记录，不能相互替代。
